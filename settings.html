GUIDE

素材与导入格式

A

Spine 模型

一套完整模型通常由骨骼数据、图集描述和一张或多张贴图组成。明日方舟基建小人需要 Spine Runtime 3.8。

character.skel + character.atlas + character.png
B

角色语音与字幕

从 Ark-Voice 下载角色整合 OGG 即可。时间轴与简中台词表已经内置，不需要手工下载 JSON 或使用 FFmpeg。

C

兼容与版权

模型导出版本必须与 3.8 Runtime 兼容。只导入你有权使用的素材；游戏角色资源不得用于商业用途或损害权利人利益。
