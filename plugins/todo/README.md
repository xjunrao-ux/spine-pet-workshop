# 待办事项内置插件

待办现为桌宠内置插件，无需导入 ZIP；仍使用统一插件接口。`example.todo` ID 特意保留，沿用旧 ZIP 版的任务、配置和已读空间。旧 ZIP 安装记录会转为内置入口，迁移前备份索引，包缓存与数据不删除。

悬停角色 → 待办 → 新增。使用右下角左右箭头查看待完成、已完成、新增/编辑页面。滚轮只滚动当前页内容。未完成条目右侧显示打勾，已完成条目右侧显示撤回；右键项目打开编辑、删除与逾期项目的稍后提醒，支持 Shift+F10 和菜单键。删除可用“撤销删除”恢复。标题、备注、截止时间在本机保存，提醒默认每 15 秒检查，可设 5–120 秒。

角色管理器可启用/禁用及调整提醒设置，禁用保留数据。内置插件不可卸载或被同 ID ZIP 覆盖。程序未运行时不弹出，重启后检查未提醒的逾期待办；字幕遵循隐私、专注、锁屏和全局提醒开关。

1.2.0（2026-10-13）：左右按钮分页；右侧只保留完成/撤回，其他操作改为项目右键菜单。沿用原 ID、配置和业务数据结构。
