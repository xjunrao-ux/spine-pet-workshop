# v2.2.4 Spine 桌宠工坊

最新 Windows x64 正式版，支持本地导入 Spine 3.8 角色与语音。

## 下载

- `Spine-Pet-Workshop-Setup-v2.2.4-x64.exe`：安装版。
- `Spine-Pet-Workshop-Portable-v2.2.4-x64.exe`：双击运行的便携版。
- `SHA256SUMS.txt`：软件包校验文件。
- `使用说明.md`：离线使用说明。

无需安装 Node.js、pnpm 或 Electron。

## 本版功能

- 默认阿米娅示例和本地角色管理。
- 导入 SKEL / JSON、atlas、贴图与自定义动作映射。
- 单句音频加字幕，或角色长音频加时间轴。
- 默认时间轴与中文字幕配置，支持用户覆盖。
- 拖动、重力、窗口吸附、尺寸调节和语音开关。
- 修正语音末尾串台、非主动轮播抢占和坐姿贴边。
- 窗口、托盘和软件包采用小兔子图标。

## 使用

首次启动会打开角色管理器；左键拖动，短按人物互动，右键人物或托盘打开菜单。完整导入步骤、素材位置和故障排查见 [使用说明](versions/v2.2.md)。

v3 音乐控制、通知及其他扩展尚未包含在本版。角色和语音素材的权利属于各自权利人，来源说明随本地素材保留。
