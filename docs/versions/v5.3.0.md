# SpinePet v5.3.0 使用说明

正式版 · 2026-10-31 · Windows x64。安装包、可选插件、校验值与源码对应 GitHub 标签 v5.3.0。版本功能范围已完成验收，后续以兼容与缺陷修复为主。

## 安装和启动

从 [v5.3.0 Release](https://github.com/xjunrao-ux/spine-pet-workshop/releases/tag/v5.3.0) 下载 SpinePet-Setup-v5.3.0-x64.exe 或 SpinePet-Portable-v5.3.0-x64.exe。普通用户无需 Node.js、pnpm 或 Electron。

安装版按向导运行；便携版放在固定位置双击运行。首次运行显示内置阿米娅与管理器。右键角色或系统托盘图标可打开角色管理器、显示/隐藏与退出；关闭管理器不会退出桌宠。

本版沿用独立的 Windows 任务栏标识，与旧 Electron/开发运行关联分开；升级时保持安装身份和用户数据目录。安装器和程序会迁移属于当前安装的快捷方式标识及图标，保留启动参数和已有快捷方式的取舍。升级后退出旧实例再打开新版。

## 管理器与素材入口

左侧五个栏目：角色库、导入角色、功能、扩展、更新与开发。主工作区与右侧角色设置独立滚动，小窗口的设置栏叠放在右侧；保存按钮固定在设置栏底部。

进入“导入角色”，页面顶部会显示整块“获取角色素材与查看导入教程”提示卡。点击“查看素材与教程”展开模型来源、语音来源、兼容说明和三个准备步骤，再次点击收起。原来单独的素材栏目已合并到这里。

角色库右上角导入按钮、页面底部导入提交按钮和扩展页导入 ZIP 按钮为固定红色，不随主题变化。

## 按角色名下载模型与语音

素材教程下方是“搜索角色模型与语音”。输入中文名、英文名、模型编号或服装系列，选择分类后点击搜索或按回车。结果抽屉默认收起，搜索后展开，也可手动收起。修改条件后再次搜索；分页使用最近一次提交的条件。

模型可选择干员基建小人（含皮肤）、干员动态立绘或敌人战斗模型。点击“下载并填入导入”，下载完整文件并自动选择骨骼与图集；也可打开精确下载页。下载支持进度、取消、失败重试和校验后的缓存复用，尚未完成的下载不会进入导入表单。

有已收录配音的角色会提供语种选择。点击“下载语音并填入”，自动填写角色 ID、语种和音频，使用匹配的内置时间轴与中文字幕并准备试听。皮肤优先匹配专属配音，共用时明确标注；没有可用语音时提示未收录。模型与语音可按任意顺序准备，最后确认预览、试听并导入。

索引包含 3,112 个模型文件夹、1,407 个音频文件的元数据。13 个敌人变体名称待核实，仍可按编号检索。搜索可离线使用，下载需要访问 GitHub 原始文件；固定快照不自动随上游更新。

## 导入步骤

1. 准备 Spine 3.8 的骨骼（.skel 或兼容 .json）、图集（.atlas）及全部贴图，保留文件夹结构。
2. 模型可以从 [Ark-Models](https://github.com/isHarryh/Ark-Models) 获取；语音可从 [Ark-Voice](https://github.com/isHarryh/Ark-Voice) 获取。请核对资源权利与版本。
3. 填写名称，选择模型文件夹；多套模型时选择对应主骨骼和图集。动作名称可先留空，自动识别常见名称。
4. 语音可跳过。方案 A 为明日方舟整合长音频，方案 B 为单句音频。单句音频可手填字幕；整合音频需确认角色 ID 与 JP/CN/EN/KR/CUSTOM 语种，内置配置自动分句并匹配简中台词。
5. 在预览中切换动作检查，必要时试听和校准；点击“导入并设为当前桌宠”。程序复制素材进角色库，不更改原文件。

## 角色库与参数

“应用”切换当前角色；“设置”在右侧打开动态预览、动作选择、语音试听和六个参数。修改后点击“保存设置”，当前角色立即应用，语音校准从下一次播放生效。

| 参数 | 含义 |
| --- | --- |
| 语音起点/终点校准 | 毫秒，分别调整分句开始与结束；负值提前、正值延后 |
| 角色大小 | 按角色独立保存，预览使用桌宠相同逻辑像素 |
| 字幕基准字号 | 随角色缩放的基准字号 |
| 语音气泡高度偏移 | 负值向上、正值向下；滑块向右提高气泡 |
| 气泡背景透明度 | 0% 不透明、100% 完全透明；文字保持清晰 |

预览下方撤销/重做，也支持 Ctrl+Z、Ctrl+Shift+Z 或 Ctrl+Y。“恢复默认”调整当前编辑值后仍需保存。关闭按钮或 Escape 收起设置；切换栏目会隐藏设置栏并保留当前编辑。

删除只移除导入到角色库的副本，原下载文件不受影响。内置示例不能删除。

## 左下角桌宠状态

框内显示当前桌宠名称，名称太长时省略，悬停可查看完整名称和状态。

- 绿色：模型加载完成且桌宠窗口正在显示。
- 红色：桌宠隐藏、正在加载、模型/页面加载失败、进程退出或无响应；具体原因显示在名称下方。

隐藏时从托盘菜单恢复显示；模型异常时选择有效角色或检查骨骼、图集、贴图和 Spine 版本。状态随显示/隐藏、切换与恢复实时更新。

## 功能与主题

功能页顺序为配色主题、应用启动、提醒与交互，然后是模块开关、兼容性和通知来源。所有全局开关自动保存。

“应用启动 → 默认开启角色语音”控制启动时是否允许角色语音，默认开启。修改后立即应用，下次启动也按保存值生效；右键菜单中的“语音与字幕”仅临时切换本次运行状态。关闭角色语音不会关闭插件消息提醒或对话文字。

配色包括石墨黑、海盐蓝、苔原绿、暖沙金、浅玫瑰与自定义。自定义主色、页面/面板背景和两级文字颜色同步到桌宠、插件与可信连接窗口。减少动画遵循应用设置及系统偏好。

音乐依赖播放器 SMTC，网易云需先开启该选项；进度与封面是否可用取决于播放器。系统通知仅接收进入 Windows 通知中心的通知，当前不支持微信/企业微信聊天提醒。隐私模式只提示来源和数量；专注模式暂停字幕。

## 插件、聊天与排序

音乐、系统通知和待办已内置。天气、Codex、DeepSeek、DSH 以及计数器通过 Release 中的独立 ZIP 选装；不要解压，在扩展页导入并确认权限。

扩展页点击插件后在右侧配置；拖动卡片改变顺序并自动保存，没有排序箭头。禁用、重启、卸载仍可用；卸载外部插件保留数据，同 ID 重装可恢复。主程序与外部插件分开更新；可在“更新与开发”或“扩展 → 检查插件更新”检查已安装插件的新版本。

- 天气 1.2.0：在管理器城市设置搜索或输入坐标，再从桌面查看当前、24 小时及 7 天预报；断网保留缓存。
- DeepSeek 1.1.1：在管理器配置自己的 API Key、人设与手工记忆；在“扩展 → DeepSeek 对话 → 对话触发与输入框”选择“鼠标悬停”或“点击角色”，默认保留悬停；拖动角色不会触发点击聊天。回复通过原有气泡显示。拖动输入框左右边缘可调宽（240–720 px），或在设置里调整宽度滑条；宽度与触发方式会自动保存。左侧手柄可移动位置，也可调不透明度或恢复跟随。右侧重复设置已移除，保留上方设置入口；发送按钮改为圆形居中箭头。服务调用按你的账户计费。
- DSH 1.1.0：需已有兼容 DSH 桥及显式授权的会话，设置连接地址与令牌后使用。桥包是 DSH 端组件，不能当作桌宠 ZIP 导入。不会自动创建 Agent、同步人格或代答审批。
- Codex 1.1.0：只读本机额度和任务状态，缺失字段显示未知，不修改任务。

## 检查更新与下载插件

“更新与开发”页提供检查更新、下载进度、更新说明、重启并安装及开发者入口。安装版默认启动后和每 6 小时检查正式版，发现新版后后台下载；由你点击“重启并安装”才升级。自动检查和自动下载均可关闭。便携版只检查版本，需打开发布页下载新版。

首次安装插件：打开发布页，在 GitHub Release 的 Assets（附件）下载插件 ZIP；回到“扩展 → 导入插件 ZIP”选择文件，无需解压。Source code.zip 不是插件。已安装且被社区收录的插件可独立检查更新，核对来源与权限后确认替换；配置、启用状态与独立数据保留，启动失败会恢复旧包。最低主程序版本或配置格式不兼容时会阻止在线更新。

v5.1.3 及更早版本没有检查更新功能，需要先手动安装一次 v5.3.0。以后安装版可直接检查并升级。

## 升级、备份和常见问题

升级前退出旧版，安装或启动新版。数据继续保存在 Windows 的 %APPDATA%\spine-pet-workshop\，与 EXE 位置无关。先退出再备份整个目录；卸载软件默认保留资料。移动便携版后，重新登记开机启动。

| 问题 | 处理 |
| --- | --- |
| 只看到源码文件 | 下载 Setup 或 Portable EXE；Source code.zip 不是安装包 |
| 找不到模型 | 在导入页输入角色名并点击搜索；确认分类或改用模型编号 |
| 下载失败或语音未收录 | 重试或打开对应下载页；未收录素材仍可通过本地方式导入 |
| 红色状态、桌宠不见了 | 查看状态文字；隐藏则从托盘显示，模型错误则检查资源或换角色 |
| 找不到点击触发或调宽设置 | 退出旧实例并安装/启动宿主 5.3.0；只更新插件 ZIP 不会更新宿主界面 |
| 插件配置或界面还是旧版 | 确认宿主已更新，再下载本次 Release 的对应 ZIP 重新导入 |
| 没有 AI 回复 | 检查 API Key/账户或 DSH 连接；两者是独立插件与连接方式 |
| 按钮无响应或面板异常 | 先退出旧实例并重启，提交复现步骤、版本与去除个人信息的截图 |

## 校验

用 PowerShell 的 Get-FileHash -Algorithm SHA256 核对下载文件，与同一 Release 的 SHA256SUMS.txt 比较。源码与打包复现方法见仓库 docs/DEVELOPMENT.md；发布验收范围见 docs/VALIDATION_v5.3.0.md。
