# v3.1.2

> 历史版本记录。当前正式版请阅读 [v5.1.2 使用说明](v5.1.2.md)。

- 开机启动按名称、当前用户与 EXE 路径匹配自己的 Windows 启动项，以该项 enabled 判断。不再依赖只检查默认应用 ID 的 openAtLogin；也不依赖会遗漏 --autostart 等开关的 launchItems.args。读写传入相同启动参数，路径加引号防止 Electron 44 错误拆分带空格路径。
- 通知启用时保留铃铛入口：新消息显示红点，查看后消除红点，无未读时显示“暂无新通知”；只有关闭通知功能才隐藏入口。
- 延续 v3.1.1 的平滑吸附、边缘缩放、预览撤销重做、高度滑块正确填色与角色管理器兼容说明。
- 提交、标签、说明和产物统一采用 v3.1.x；本版包位于 release/v3.1.2/。v3.1.1 是本地历史版本，不单独公开发布。

## 升级与验证

保留本机角色与设置。换用新版便携 EXE 后，在“功能 → 应用启动”重新开启开机启动，以更新旧版本登记路径。应用不会自动写入启动项。

验证命令：pnpm build；node --test scripts/test-character-parameters.mjs scripts/test-extensions.mjs scripts/test-startup.mjs；pnpm exec electron scripts/smoke-v231.mjs；使用 PET_TEST_PROFILE 与 V311_SMOKE_DIR 的隔离菜单回归。

check-startup-windows.mjs 只读核对真实 Windows 启动项，不写注册表，不执行注销或重启。完整说明见 [v3.1](v3.1.md)。
