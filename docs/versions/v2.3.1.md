# v2.3.1 开发版使用说明

此版本尚未发布 GitHub Release，基础功能已同步到本地 `dev/v3`。本轮参数扩展在当前 v3 工作区开发并单独提交，保留其它未提交开发改动。公共正式版保持不变。

## 导入前预览

在“导入角色”中选择模型文件夹、主骨骼和图集，页面底部“角色预览与参数”会加载角色。预览动画下拉框可以查看模型实际提供的各个动作；不会切换桌面正在使用的角色。

## 手动校准音频

选择长音频并填写角色 ID 后，点击“读取长音频分句以试听”。选择台词试听，分别调整“语音起点校准”和“语音终点校准”的滑条或数值框，再次试听。单位为毫秒：起点 `-250` 表示提前 0.25 秒开始；终点 `+250` 表示延后 0.25 秒结束。两者相同可整体平移，不同可延长或缩短选段。只调整选段，不修改源文件或原始时间轴。起点必须早于终点；越过音频范围会裁切或不播放。旧版整体校准值会自动迁移到两端。

推荐先试听靠前和靠后的几句。若偏差不是固定数值而是逐渐累积，统一偏移无法完全修复，应更新匹配该音频的时间轴。

## 气泡、大小与方向

“语音气泡高度偏移”支持滑动和输入，负值向上、正值向下，预览实时展示；窗口之外的位置会自动限制在可见区域。默认“左右随机”：每次进入行走动作重新选择方向，不保证每次交替，也不会每帧反复抖动。可以改为优先向左或右，到达边缘仍会转向。

新增“不要走动”：保存后立即停止移动，不再自动或手动行走，但仍可拖动。“气泡背景透明度”只改变底色，0% 不透明、100% 完全透明，文字不随背景消失。

“角色大小”支持 30%～120%，每个角色单独记忆，右键大小菜单也会保存此设置。“字幕基准字号”可独立调节，并自动随角色比例变化：小角色文字适当缩小、大角色文字适当放大；长句更紧凑，默认气泡位置尽量不遮住人物。过长台词仍可能遮挡，可进一步减小基准字号或调整气泡高度。

导航顺序调整为“角色库 → 素材与格式 → 导入角色”，先了解素材再导入；底部状态栏背景调淡，状态文字放大。

## 修改已导入角色

角色库中每个角色（含内置阿米娅）都有“设置”按钮。打开后可以预览模型、试听语音、修改参数或恢复默认。点击“保存设置”后仅更新这个角色。当前角色的气泡立即更新，音频偏移和初始方向从下一次播放／行走应用。切换其他角色不会覆盖设置。

## 开发验证

```powershell
node --test scripts/test-character-parameters.mjs
pnpm build
pnpm exec electron scripts/smoke-v231.mjs
```

Electron 回归需要本地内置模型和语音素材，使用 `.local/smoke-v231/` 下的独立资料目录，不修改日常角色库。截图和测试资料不上传仓库。
