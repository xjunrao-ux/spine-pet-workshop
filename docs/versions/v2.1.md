# v2.1 使用说明

> 历史版本记录。当前正式版请阅读 [v5.1.2 使用说明](v5.1.2.md)。

## 安装

### 安装版

下载 `Amiya-Desktop-Pet-Setup-v2.1.1-x64.exe`，双击运行，可选择安装位置并创建桌面及开始菜单快捷方式。

### 便携版

下载 `Amiya-Desktop-Pet-Portable-v2.1.1-x64.exe`，保存到希望长期使用的位置后双击运行。不需要安装，不要放在浏览器临时下载目录中长期使用。

## 操作

- 左键短按人物：触发互动动作。
- 左键按住人物：拖动桌宠；拖动方向会改变人物朝向。
- 右键人物：打开动作、尺寸、重力、吸附、置顶和语音菜单。
- 左键单击系统托盘图标：显示或隐藏桌宠。
- 右键单击托盘图标：打开设置菜单或退出。

## 桌面行为

- 开启重力后，桌宠会落到任务栏顶部。
- 同时开启窗口吸附后，桌宠也可以落在符合条件的软件窗口上沿。
- 行走到屏幕或窗口边缘时会自动转身。
- 大小可使用 40%～80% 预设，也可以在 30%～120% 范围内自定义。

## 常见问题

### 桌宠不见了

先检查系统托盘，左键单击托盘图标即可重新显示。仍未出现时，从托盘菜单退出后重新启动。

### 无法吸附到软件窗口

确认重力和窗口吸附均已开启。最小化窗口、无标题窗口以及尺寸过小的窗口不会作为吸附目标。

### Windows 提示来源未知

当前安装包没有商业代码签名证书。只从项目 GitHub Releases 下载，并使用同一版本的 `SHA256SUMS.txt` 核对哈希。

### 如何彻底退出

关闭或隐藏桌宠不一定结束后台进程。请右键系统托盘图标并选择“退出”。
