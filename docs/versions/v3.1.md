# v3.1 使用说明

当前发行版本为 v3.1.2，支持 Windows x64，不接入 AI 对话。

## 安装与运行

Setup 安装版双击安装；Portable 便携版放在固定位置直接运行。无需 Node.js、pnpm 或 Electron。升级保留角色库与参数，请先退出旧版避免重复桌宠。

首次打开桌宠与角色管理器。右键角色或托盘、或悬停胶囊最右侧设置均可打开管理器。模型与语音导入沿用 [v2.2 素材说明](v2.2.md)。

## 胶囊与面板

悬停角色展开胶囊；左侧图标可用滚轮横向浏览，右侧设置固定。悬停图标预览、点击固定；再点当前图标或图钉取消固定，Esc / 关闭收起。

音乐按播放器分页，通知按每条消息分页，Codex 分额度与最近任务。标题固定，长正文页内滚动，到边界继续滚动带动整页，停下后平滑吸附。支持 PageUp / PageDown。拖动边缘或角调整面板，尺寸自动保存。

## 功能与边界

- 音乐：播放／暂停、切歌、曲目、歌手及可读取的封面。按钮取决于播放器上报能力，不监听桌宠自身语音。
- 网易云：开启客户端 SMTC（系统媒体控制）。时长／进度暂不可读取，显示 --:--。兼容提示在管理器“功能”页。
- 通知：接收进入 Windows 通知中心的 QQ、手机连接等来源，首次在“功能”页请求通知访问。微信和企业微信当前不走系统通知，暂不支持聊天提醒。
- 显示模式：字幕简要展示标题与正文；隐私模式只提示来源与新消息数量。正文不写入日志或历史文件。
- 通知入口启用时常驻，新消息有红点，查看后消除；无未读时显示空状态，关闭功能才隐藏。只清除桌宠提醒，不删除 Windows 通知、不设置聊天已读。
- Codex：运行时只读显示额度、重置时间、可读取任务状态，约 15 秒刷新。不调用模型、不启动任务；明确完成／失败／中断才提醒，历史任务不重复弹出，数据缺失显示未知。
- 专注模式继续采集、不弹字幕；减少动画取消滚动过渡；关闭模块停止相应采集。

## 开机启动

在“功能 → 应用启动”手动开启，默认关闭。登录 Windows 后运行桌宠，不主动弹管理器；开发运行不可登记。

便携版移动、改名或换版本路径后，打开新文件重新开启该开关。登记的是外层 EXE，不是解压临时目录，只管理自己的启动项。

## 预览与参数

预览采用实际角色比例与气泡定位；60% 为 252×300 DIP，大模型可滚动查看、不二次缩小。预览下方提供撤销／重做，快捷键 Ctrl+Z、Ctrl+Shift+Z / Ctrl+Y，一次滑块拖动记一步。

高度滑块向右提高气泡，颜色仍由左到右填充；数值框负值向上、正值向下。修改参数需点击保存，仅影响该角色。不再提供固定行走方向参数，保留随机左右行走。

第三方插件、时间任务、待办、笔记及 AI 功能留待后续版本。详情见 [v3.1.2](v3.1.2.md)。
