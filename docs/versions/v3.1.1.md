# v3.1.1

本地开发版本，开发分支为 `dev/v3`，不接入 AI 对话。后续修复使用独立的 v3.1.x 版本提交，不再用版本后缀区分。

## 菜单与交互

- 鼠标停留角色约 300 毫秒后展开圆角胶囊；左侧入口可横向滚动，右侧设置按钮固定。
- 图标悬停约 180 毫秒预览详情，点击固定。固定后悬停不切换；再点当前图标或图钉取消固定。
- Esc、关闭按钮或固定卡片失焦收起面板。菜单与设置支持反复打开，最小化设置窗口可恢复。
- 浮层置于角色和语音气泡之上；透明空白区域鼠标穿透。角色重力保持运行，交互期间横向行走缓慢减速，菜单位置稳定。
- 淡入约 160 毫秒、淡出约 220 毫秒。背景不透明度约 80%，文字不透明。支持减少动画。
- 面板四边和角可拖动调整宽高，尺寸持久化且不影响角色大小：宽 240–560、高 230–640 DIP，并受屏幕工作区限制。
- 角色管理器“功能”控制模块开关、消息隐私与开机启动；“扩展”展示内置模块与未来接口。

## 内容与滚动

- 每条通知独立一页，来源标题固定，正文页内滚动。音乐按播放器分页，Codex 分为剩余额度与最近任务两页。
- 滚轮连续移动内容，长正文优先页内滚动，边界剩余滚动量流入整页；停下约 160 毫秒后平滑吸附最近一页。
- 不丢弃快速滚轮输入，采集刷新不打断滚动。支持 PageUp / PageDown；减少动画模式取消过渡。
- 系统通知用铃铛图标，Codex 与 ChatGPT 来源用 OpenAI / GPT 图标。

## 音乐与通知

- 音乐支持系统媒体会话、曲目／歌手／封面、播放／暂停和上一首／下一首；按播放器上报能力启用按钮。排除桌宠自身语音会话。
- QQ 音乐封面本地规范化为最多 256 像素 PNG。无封面显示音乐图标，不伪造图片。
- 网易云需在客户端开启 **SMTC（系统媒体控制）**。当前不支持读取其时长和播放进度，显示 `--:--`。说明放在角色管理器“功能 → 兼容性说明”，不占用悬浮音乐卡片。
- 无系统媒体会话时可尝试兼容按键；其他播放器活动时禁用，避免误控。不能保证读到曲目、封面或真实状态。
- 只接收真正进入 Windows 通知中心的消息，包括 QQ、手机连接等。微信与企业微信当前不走系统通知，暂不支持聊天提醒，等待官方可用接口。不读取聊天数据库。
- 显示模式弹出简短标题和正文，摘要最多两行；隐私模式只提示来源和新消息数量。默认隐私模式，正文不落盘。
- 通知页停留约 650 毫秒算浏览，离开面板后移除桌宠已查看提醒。只保存通知 ID 与创建时间（最多 1000 条），不修改系统或聊天已读状态。
- 启动前 ChatGPT 历史通知不再展示，只提示新增通知。专注模式继续采集但不弹字幕，锁屏不显示面板。

## Codex 与扩展边界

Codex 运行时读取本机额度、重置时间、最近任务与明确的执行完成／失败／中断状态，约 15 秒刷新；不调用模型、不启动任务，不把“空闲”当作完成。数据未返回时显示未知。Windows 媒体与通知约 2 秒刷新。

第三方插件暂未开放。内置模块遵循统一身份、权限、状态、事件与操作接口，未来方向见 [扩展接口](../EXTENSIONS.md)。

## 预览与角色参数

- 导入和角色设置预览使用桌宠同一缩放、气泡定位公式。60% 对应 252×300 DIP；大模型不再二次缩小，可滚动查看。
- 两处预览下方提供撤销／重做图标。Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做；一次滑块拖动记一步，最多 80 步。
- 高度滑块向右提高气泡，仅反转数值映射，颜色仍从左到右填充。数值框负值向上、正值向下，旧配置含义不变。
- 移除行走方向参数，保留随机左右行走与边缘转向。角色参数逐角色保存，调整后需点击保存。

## 启动与验证

开机启动位于“功能 → 应用启动”，默认关闭。开发运行不设置启动项；便携版登记外层 EXE，移动文件后重新切换开关。登录启动不弹角色管理器。v3.1.1 存在自定义启动项状态误判问题，由 v3.1.2 修复。

验证：`pnpm build`；`node --test scripts/test-character-parameters.mjs scripts/test-extensions.mjs scripts/test-startup.mjs`；`pnpm exec electron scripts/smoke-v231.mjs`；菜单回归使用 `PET_TEST_PROFILE` 和 `V311_SMOKE_DIR` 隔离配置运行 `pnpm exec electron .`。测试仅使用模拟正文，真实桥接只输出来源与连接状态。

OpenAI 标识来自 [Simple Icons 13.0.0](https://github.com/simple-icons/simple-icons/blob/13.0.0/icons/openai.svg)（CC0）。Windows 登录启动接口参见 [Electron 文档](https://www.electronjs.org/docs/latest/api/app#appsetloginitemsettingssettings)。
