# v3.2.2

正式发布于 2026-10-13；完整使用教程见 [v3.2](v3.2.md)，更新概览见 [Release 说明](../RELEASE_v3.2.2.md)，测试结果见 [验收报告](../design/v3.2.2-validation.md)。

内置待办 1.2.0：右侧完成/撤回，右键编辑/删除，截止提醒和删除撤销。内容页改为左右箭头分页，滚轮只滚动当前页，表单草稿和内部滚动位置保留。

ZIP API v1：独立存储、角色提醒、受控天气查询、Codex 只读订阅；沙盒不开放任意网络/文件/Node。天气 1.1.0 和 Codex 1.1.0 为外部 ZIP，不随宿主预装。天气云朵图标与城市副标题；旧安装包需重新导入新版，EXE 更新不会自动替换插件。

升级保留角色与设置；旧 ZIP 待办转为内置，旧 Codex 配置/已读标识兼容保留。没有插件市场、自动更新或发布者签名。开发过程报告中的 v3.2.1 为本地验证阶段，不单独发行。
