# v4.1.1 · DeepSeek API 对话插件

> 历史版本记录。当前正式版请阅读 [v5.1.2 使用说明](v5.1.2.md)。

本版增加宿主受控 `ai.deepseek` 能力，并提供单独导入的 DeepSeek 对话 ZIP。原有音乐、通知、待办及外部天气/Codex 插件继续使用插件 API v1。

## 使用

1. 使用 v4.1.1 宿主启动，打开“角色管理器 → 扩展 → 导入插件 ZIP”。
2. 选择 `DeepSeek-Plugin-v1.0.0.zip` 并确认 API 调用、本插件存储和提醒权限。
3. 点击“配置 DeepSeek API Key”，在宿主专用窗口保存 Key、测试连接。密钥不发给插件，不显示在页面快照中。
4. 打开桌宠聊天图标，在底部单行输入条输入消息，点击右侧向上箭头或按 Enter 发送。输入条固定在底部，翻看历史时仍可输入；生成中可编辑下一条草稿，右侧按钮用于停止。插件保留重试、清空确认、本地历史、人设和手工记忆。
5. 模型在管理器的 DeepSeek 插件设置里选择；通过左右翻页编辑人设、记忆或打开连接设置。

默认模型 `deepseek-flash`，另支持 `deepseek-v4-pro`。仅 DeepSeek 官方 API，费用计入用户账户；不需要 DSH，不调用本地工具。对话历史、人设和手工记忆会在发送消息时作为上下文交给服务商。

## 实现边界

- 宿主对每个插件身份分别保存加密凭据，使用固定 HTTPS 目标，拒绝重定向。插件不能指定 URL、HTTP headers、工具定义或读取 Key。
- 凭据输入采用独立宿主窗口、隔离会话、来源检查与最小 IPC。Key 不进入插件独立存储、全局设置、快照和日志。
- 生成操作快速返回请求标识，后续以事件传输，避免占用插件的短命令超时。宿主负责请求数量、长度、取消和超时限制。
- 新增通用声明式 `chat` 组件，模型输出按文本转义显示，不执行 HTML；页面可声明独立的 `footer` 区域，聊天使用紧凑的 `composer` 表单，历史独立滚动。更新本次主程序后重新导入插件 ZIP 即可获得新版输入区。
- 历史保留最近 20 条、60000 字符；未完成输出不作为后续上下文。记忆由用户手动编辑，尚无自动提取或向量检索。
- 升级保留现有数据。新插件请求了旧宿主不认识的权限，所以必须先升级宿主再导入插件。

## 验证

`pnpm test:deepseek` 验证加密存储隔离、流式 UTF-8 分片、异常/取消/超时、权限撤销和人格历史行为；`pnpm test:deepseek:sandbox` 在实际 Electron 沙盒和声明式界面中验证 ZIP 导入、宿主凭据窗口、发送、停止、历史恢复和禁用取消。模拟服务不产生真实 API 费用。账户可用性以用户主动执行的连接测试为准。
