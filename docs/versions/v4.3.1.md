# SpinePet v4.3.1（本地开发）

> 历史版本记录。当前正式版请阅读 [v5.1.2 使用说明](v5.1.2.md)。

本轮只创建本地 commit，不推送远端仓库，不创建 GitHub Release。

本地修复版请运行 `release/v4.3.1-hotfix/win-unpacked/SpinePet.exe`。修复输入条尺寸同步、后台刷新干扰设置点击，以及浮层遮挡设置的问题；旧的 `release/v4.3.1/` 目录保留用于回溯。详见 [修复验收](../design/v4.3.1-hotfix-validation.md)。

## 配色与图标

右键角色 → 角色管理器 → 功能 → 配色主题。默认石墨黑，保留海盐蓝、苔原绿、暖沙金、浅玫瑰，增加“自定义”。选择自定义后，可修改主色、页面背景、面板背景、主要文字与次要文字；选择后自动保存，功能菜单、角色气泡、AI 输入框、插件设置与连接弹窗同步应用。

移除旧雾蓝灰模板；旧配置中的 `slate` 自动映射到石墨黑。其他已选模板及自定义颜色保留。切换模板不会调用模型或重连 DSH。

配色卡片使用透明背景的画板 SVG；应用图标使用 [透明 PNG](../../assets/spinepet-icon.png) 和多分辨率 ICO，不再带白色方底。[图标来源与制作记录](../../assets/SpinePet_ICON.md)。

## AI 输入框

需要已启用的 DeepSeek 对话 v1.1.0 插件；已有同版本 ZIP 可直接沿用，无需重装。将鼠标放到角色模型上，即显示独立输入框，无需打开快捷菜单。输入框左侧六点手柄可拖动到桌面任意位置，独立于角色窗口、功能菜单和 DSH 面板。

默认跟随角色；手动拖动后保存为固定桌面位置，重启恢复。角色管理器 → 扩展 → DeepSeek 对话 → 输入框外观与位置：

- 输入框不透明度：0–100%，默认 86%；只调整背景，文字与按钮保持清晰。
- 恢复输入框跟随角色：清除手动位置，重新靠近角色。
- 输入框不再显示“已配置 · 模型”等常驻状态；连接状态、模型、人设与记忆在此设置面板查看和修改。发送失败时会临时显示错误提示。

Enter 发送，中文输入法确认候选时不发送，生成中可停止，Esc 收起。回复继续通过角色原有、可校准的气泡流式显示。拖动、调透明度、配色和位置保存都不会自行发送 AI 消息。

输入框保存的屏幕坐标会按当前显示器可用区域约束；移动显示器或改变分辨率后，窗口不会恢复到不可见区域。禁用插件、锁屏或隐藏角色后，输入框收起；重新启用不重播旧回复。

## 更名与兼容

产品、可执行文件与快捷方式名称为 SpinePet，安装/便携文件分别采用 `SpinePet-Setup-v4.3.1-x64.exe` / `SpinePet-Portable-v4.3.1-x64.exe` 的命名规则。

应用内部 ID 和旧的 `%APPDATA%/spine-pet-workshop` 用户目录维持一致，角色、插件、API 密钥、本地连接及历史仍在原处。现有旧启动项可读取；只有用户在设置中显式切换开机启动时才调整对应登记。移动或更换可执行文件后，应重新登记开机启动。

本轮全为宿主修改；DeepSeek v1.1.0、DSH v1.1.0、天气 v1.2.0 ZIP 可沿用。主程序本地构建后运行 `release/v4.3.1/win-unpacked/SpinePet.exe`；保留整个目录的资源文件。更早的 AI / DSH ZIP 需要手动重新导入新版才能使用 bubble 呈现与鲸鱼声明。

## 开发与验证

新增全局配置：`customTheme`（五个 #RRGGBB 字符串）、`companionOpacity`（0–100）、`companionPosition`（屏幕坐标或 null）。自定义颜色只接受十六进制 RGB，不允许 CSS、URL 或脚本；部分更新保留其他颜色。纯外观更新不调用插件设置回调。

聊天使用独立透明 BrowserWindow，复用宿主验证过的 composer 命令；角色窗口只接收最后一条助手回复。发送/拖动/调整尺寸均校验对应本机窗口主 frame，执行前校验插件 ID、生命周期 epoch、当前表单、输入长度和 pending 状态。角色回复、会话配置、密钥及 DSH 的权限边界维持原设计。

验证命令：
```powershell
pnpm build
pnpm test:release
pnpm test:ui-themes
node --test scripts/test-deepseek.mjs scripts/test-dsh-pet.mjs scripts/test-plugin-presentation.mjs
pnpm test:companion-ui
pnpm test:ui-main
pnpm test:dsh-pet:sandbox
```

图形测试使用隔离用户目录、真实角色模型、插件 Worker 与 HTTP/SSE，模型/天气/Harness 内容用测试替身；不向真实计费模型或现有 DSH 会话提交请求。结果与截图位于 `.local/v4.3.1-ui-validation/` 和 `.local/v4.3.1-main-smoke/`。
