# v5.1.1 · 管理器排版更新

> 历史版本记录。当前正式版请阅读 [v5.1.2 使用说明](v5.1.2.md)。

本版主要调整角色管理器的排版与视觉。保留 SpinePet 名称、应用 ID、用户数据目录和现有功能；不引入新的 AI 服务、插件接口或角色设置项。本次仅本地提交。

## 三栏工作区

- 左侧集中显示品牌、版本和原有的角色库、导入角色、功能、扩展入口；素材与导入格式说明合并到导入页顶部的折叠区，原有下载链接保留。底部显示当前桌宠名称和实际状态：正常显示为绿色，隐藏、加载失败或进程异常为红色，悬停可查看完整名称与原因。
- 中间角色库使用响应式卡片网格。缩略图来自本地真实模型，只为可见区域生成静态图片，并共用一个离屏渲染器；预览失败时仍可使用卡片上的原有操作。
- 点击角色的“设置”，在右侧独立设置栏查看原有动态预览、动作选择、语音试听、全部参数及撤销/重做。调整后仍需点击“保存设置”。
- 设置栏底部固定保存状态、恢复默认和保存按钮；关闭按钮或 Escape 可收起设置栏并返回原卡片。切换导航时隐藏设置栏，回到角色库可继续当前编辑。
- 角色库右上角的导入入口加大并使用固定红色；导入提交、插件 ZIP 导入同样使用固定红底白字，切换主题或自定义主色时保持不变。导入内容和处理方式保持一致。
- 功能页按“配色主题 → 应用启动 → 提醒与交互”排列，后续插件开关与说明继续保留。扩展页移除排序箭头，通过拖动卡片调整顺序。

## 主题与窗口

默认主题仍是石墨黑。功能页保留石墨黑、海盐蓝、苔原绿、暖沙金、浅玫瑰和自定义入口，以及主色、页面背景、面板背景、主要文字、次要文字五项自定义颜色。新增布局复用这些配色变量，继续通过原有自动保存与同步机制生效。

管理器初始尺寸以 1280 × 820 为上限，并根据当前屏幕工作区留出边距，最小尺寸仍为 760 × 620。宽窗口将设置栏放在工作区右侧；较窄窗口将其叠放在右侧，角色库与设置正文各自滚动。导航和保存按钮保持可见。卡片悬停动效遵循应用“减少动画”设置及系统减少动画偏好。

## 验证

- `pnpm build`：TypeScript 与 Vite 构建。
- `pnpm test:manager-layout`：隔离用户目录运行真实 Electron 主程序，检查模型缩略图、网格、设置栏参数保存、全部主题与自定义颜色、窄窗口滚动、角色导入、切换和删除，以及真实隐藏/显示、无响应、模型损坏与恢复的状态同步。
- `pnpm test:ui-themes`：主题、用户配置迁移及自定义颜色校验。
- `pnpm test:companion-ui`：既有插件设置、输入框及动态刷新交互回归。

管理器回归截图和结果保存在本地忽略目录 `.local/v5.1.1-manager/`，不进入源码提交或公开发布。
