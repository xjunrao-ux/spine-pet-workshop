# v3.2 使用说明：v3.2.3

> 历史版本记录。当前正式版请阅读 [v5.1.2 使用说明](v5.1.2.md)。

适用 Windows x64，正式版本 v3.2.3。从 [本版本下载页](https://github.com/xjunrao-ux/spine-pet-workshop/releases/tag/v3.2.3) 获取 EXE 和可选插件。

## 1. 下载、启动与升级

安装版双击安装，便携版放在固定文件夹直接运行；普通用户无需 Node.js、pnpm 或 Electron。GitHub 的源码 ZIP 不是运行包。

升级先从角色或托盘右键菜单退出旧版，再打开新版。已有角色库和设置保留；退出后备份 `%APPDATA%\spine-pet-workshop\` 可保留角色、参数、插件配置及业务数据。便携版仍使用这个目录存储，不会把角色库放到 EXE 旁。

| 需要什么 | 下载什么 | 下一步 |
| --- | --- | --- |
| 桌宠、角色导入、音乐、通知、待办 | Setup 或 Portable EXE，二选一 | 启动即可 |
| 城市天气和预报 | Weather-Plugin-v1.1.0.zip | 管理器 → 扩展 → 导入 ZIP |
| 本机 Codex 额度/任务状态 | Codex-Plugin-v1.1.0.zip | 导入 ZIP，再保持本机 Codex 已登录并运行 |
| 核对下载完整性 | SHA256SUMS.txt | PowerShell 使用 Get-FileHash -Algorithm SHA256 比较 |

开机启动默认关闭，在“功能 → 应用启动”启用。更新便携文件名或路径后，关闭再开启该选项以更新登记路径。

## 2. 打开管理器与浏览页面

右键角色 → 打开角色管理器，或点击胶囊最右侧齿轮。管理器包含角色库、素材与格式、导入角色、功能、扩展五个栏目。

悬停功能图标预览，点击图标固定；再次点击或图钉可取消固定，Esc/关闭按钮收起。胶囊图标可横向滚轮浏览；内容面板通过**右下角左右箭头**翻页。滚轮只浏览当前页内容，到底也不会自动翻页。左右方向键和 PageUp/PageDown 同样可用；输入框编辑时不会误触翻页。拖动面板边缘可调整大小。

## 3. 内置待办：右侧完成，右键编辑

打开清单图标 → 新增待办 → 填标题 → 添加；备注与截止时间可留空。

![待办：右侧打勾与底部左右翻页](https://raw.githubusercontent.com/xjunrao-ux/spine-pet-workshop/v3.2.3/docs/images/v322-todo-pending.png)

右侧打勾完成，下一页“已完成”的撤回按钮恢复。右键事项打开编辑/删除，或用 Shift+F10/菜单键；删除后“撤销删除”可恢复最近删除项目。到期事项的右键菜单还有“10 分钟后提醒”。

![待办右键项目菜单](https://raw.githubusercontent.com/xjunrao-ux/spine-pet-workshop/v3.2.3/docs/images/v322-todo-context-menu.png)

任务本机保存。管理器“扩展 → 待办 → 设置”可控制提醒和检查间隔。程序退出或待办禁用期间不会提醒；再次运行时检查未提醒的逾期任务。内置待办无需 ZIP，原 ZIP 任务与配置继续沿用，禁用保留数据，不能卸载内置项。

## 4. 安装或更新插件 ZIP

下载 ZIP 后不要解压。打开“扩展”，点击“导入插件 ZIP”，选择文件，核对名称、版本和权限后确认；列表显示“运行中”后使用对应图标。

![导入 ZIP 的入口和插件列表](https://raw.githubusercontent.com/xjunrao-ux/spine-pet-workshop/v3.2.3/docs/images/v322-plugin-import.png)

**更新 EXE 不会自动更新已安装插件。** 更新天气或 Codex 时，再次导入新版同 ID ZIP；原设置与业务数据保留。扩展页可重启、禁用、卸载外部插件；卸载保留数据，同 ID 重装可恢复。没有插件市场或自动更新。

## 5. 天气：云朵图标与所选城市

导入天气 ZIP 后点击云朵 → 城市设置 → 输入城市名 → 搜索城市 → 核对候选省份/国家 → 选择。至少输入 2 个字符；中文搜索无结果时试拼音/英文，如 Hangzhou，也可输入名称及 WGS84 经纬度。

![城市搜索与经纬度输入](https://raw.githubusercontent.com/xjunrao-ux/spine-pet-workshop/v3.2.3/docs/images/v322-weather-location.png)

当前天气、未来 24 小时、7 天预报通过左右箭头切换。预报副标题显示所选城市，Asia/Shanghai 等仅是内部时区。手动刷新按钮位于当前天气页；断网仍显示已保存缓存并提示失败或过期。

![云朵、城市副标题和 7 天预报](https://raw.githubusercontent.com/xjunrao-ux/spine-pet-workshop/v3.2.3/docs/images/v322-weather-forecast.png)

图中是演示数据，不代表实际天气。扩展 → 天气 → 设置、权限与兼容说明可切换摄氏/华氏、自动刷新和间隔；默认 30 分钟，宿主共享缓存可能让短时间刷新返回相同获取时间。

天气无需密钥，通过受控接口把城市或坐标发送给 Open-Meteo，服务可看到来源 IP；不使用设备定位，不读取其他插件数据。免费接口非商业使用，当前天气为模型估算，不提供官方灾害预警。详情见 [天气说明](https://github.com/xjunrao-ux/spine-pet-workshop/blob/v3.2.3/examples/weather-plugin/README.md)。

## 6. Codex、音乐与通知

Codex 已改为可选 ZIP；从 v3.1.2 升级也需要导入。它只读额度和任务状态，可能包含任务名称；不调用模型、不创建或修改任务。缺少数据时显示未知。禁用/卸载停止订阅。旧内置项配置与桌宠已读标识兼容保留。

音乐依赖播放器的 Windows 系统媒体接口，网易云需启用 SMTC，时长/进度显示 --:--。系统通知需请求 Windows 通知访问；来源应用必须真正发送到系统通知中心。当前验证的微信/企业微信聊天通道不支持，应用内或托盘未读不等于系统通知。

隐私模式隐藏字幕正文，专注模式抑制主动字幕；查看只改变桌宠自身已读，不删除系统通知或修改聊天已读。兼容限制也显示在管理器中。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 天气仍是时钟图标，副标题还是 Asia/Shanghai | 更新宿主到 v3.2.3，再导入本 Release 的天气 v1.1.0 ZIP；扩展列表核对版本 |
| 搜索城市无结果 | 使用拼音/英文或经纬度，检查网络 |
| 天气刷新失败 | 缓存保留；网络恢复后点击刷新，或等待自动检查 |
| 找不到编辑/删除按钮 | 右键待办项目或使用 Shift+F10 |
| 滚轮不翻页 | 使用右下角左右箭头；滚轮只浏览当前页 |
| Codex 没有入口 | 先安装 Codex ZIP，再检查本机已登录、运行和权限 |
| 重装插件后数据仍在 | 卸载默认保留数据，同 ID 重装恢复，这是当前行为 |
| 更新后开机启动仍打开旧 EXE | 在新版关闭再开启开机启动，更新旧路径 |

角色模型、动作映射、语音导入和参数图文说明见 [完整 README](https://github.com/xjunrao-ux/spine-pet-workshop/blob/v3.2.3/README.md)。只安装可信来源，API v1 尚处验证阶段；源代码、Spine Runtime、角色素材、天气数据的许可范围分别适用。
