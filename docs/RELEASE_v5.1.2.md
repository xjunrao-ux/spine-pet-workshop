# SpinePet v5.1.2

Windows x64 正式版 · 2026-10-22

本版完成管理器体验、说明文档与发行整理，保留已有角色、主题、参数和插件数据。

## 本版变化

- 三栏角色管理器：固定侧栏、真实模型卡片、独立设置与保存栏。
- 导入页顶部新增醒目的素材准备卡片，明确提供下载来源、模型要求和导入教程。
- 角色/插件导入使用固定红色主按钮；预设主题与自定义配色继续可用。
- 左下角显示当前桌宠名称与真实状态：正常显示为绿色，隐藏、加载或异常为红色并说明原因。
- 启动、提醒与交互紧随主题设置；插件用拖动排序。
- 保留逐角色参数、撤销/重做、语音试听、内置待办，以及独立 AI 输入框和设置交互修复。
- 汇总使用、开发、发布和验证文档，正式源码排除旧研究与过程记录，清理重复测试缓存和中间构建。

## 下载文件

- SpinePet-Setup-v5.1.2-x64.exe：安装版。
- SpinePet-Portable-v5.1.2-x64.exe：便携版。
- Weather-Plugin-v1.2.0.zip、Codex-Plugin-v1.1.0.zip、DeepSeek-Plugin-v1.1.0.zip、DSH-Pet-Plugin-v1.1.0.zip、Hello-Counter-v1.0.0.zip：按需导入的桌宠插件。
- local-dsh-pet-bridge-1.0.0.tgz：供兼容 DSH 宿主安装的桥组件，不是桌宠 ZIP。
- USAGE-v5.1.2.md、SHA256SUMS.txt：离线使用说明与全部附件校验值。

升级前退出旧版。用户数据目录保持不变；需要更新插件时重新导入本次 ZIP，主程序不会自动替换已有 ZIP。便携版移动位置后请重新登记开机启动。

支持 Spine 3.8 与 Windows 系统媒体/通知接口。微信/企业微信聊天提醒、自动更新、DSH 自动创建 Agent/审批/人格同步不在本版范围。DeepSeek 账户费用由用户承担。
