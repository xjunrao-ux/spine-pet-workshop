# v2.1.1 阿米娅桌宠

固定阿米娅角色的 Windows x64 正式版，包含动作、语音和简体中文字幕。

## 本版变化

- 调整置顶窗口层级，改善人物被任务栏或其他窗口遮挡的问题。
- 使用小兔子图作为窗口、托盘、安装包和程序图标。
- 保留拖动、重力、窗口吸附、坐姿、自动行走和尺寸调整。

## 下载与运行

- `Amiya-Desktop-Pet-Setup-v2.1.1-x64.exe`：双击安装，然后从桌面快捷方式启动。
- `Amiya-Desktop-Pet-Portable-v2.1.1-x64.exe`：双击直接运行。
- 无需安装 Node.js、pnpm 或 Electron。

详细操作见 [v2.1 使用说明](versions/v2.1.md)。自定义角色导入从 v2.2 开始提供。

角色模型和语音来源见本地素材中的 SOURCE.md；其权利归相应权利人所有。
