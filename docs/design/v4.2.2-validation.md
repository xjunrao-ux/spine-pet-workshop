- `pet-dsh/1` 协议与 JSON Schema；通用宿主不导入 DSH 契约，现有 DSH 骨架保留并明确标注不属于本次交付。

- 地址与路径限制、直接 loopback 连接（无代理/重定向/cookie/共享连接池）、限额、取消/超时、权限撤销及迟到回调隔离。
