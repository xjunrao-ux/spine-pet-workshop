# 独立待办 ZIP 插件：实现与验收

> 历史开发记录。v3.2.2 已整理为正式版本，当前行为与验证见 [正式验收](v3.2.2-validation.md) 和 [图文使用说明](../versions/v3.2.md)。

> 本文为先前 ZIP 待办阶段的历史验收。当前待办已内置并沿用原数据身份，Codex 改为外置，详见 [内外置切换验收](plugin-transition-validation.md)。下面的旧包与文件路径不代表当前分发方式。

日期：2026-10-12。开发分支：dev/v3。宿主开发版本：v3.2.1。ZIP 插件版本：1.0.0。此文件是实现与验证记录，不是已冻结的完整插件开发手册。

## 独立性

待办源码位于 `examples/todo-plugin/`，只包含清单、Provider 与示例说明，不导入宿主文件。插件不在内置注册表中，也不随应用自动安装。`release/plugins/Todo-Plugin-v1.0.0.zip` 内含根目录 `plugin.json`、`provider.js` 和 `README.md`。

角色管理器 → 扩展 → 导入插件 ZIP，选择文件并确认权限后，安装记录保存在本机用户配置目录。没有上传到互联网。未安装时没有待办入口，禁用时停止运行并隐藏入口，卸载移除注册但保留数据和包缓存，重新导入相同 ID 恢复任务。

新增任务、编辑、完成/恢复、删除撤销、截止时间提醒与稍后 10 分钟提醒均由 ZIP 中的 Provider 实现。主程序只增加通用安装、运行、独立存储、表单组件与命令导航能力；菜单、吸顶标题、滚动、主题和字幕仍由宿主统一渲染。

## 权限与执行边界

- 导入先检查 ZIP 路径、大小、CRC、重复文件、链接、版本和权限，不按任意目录路径解压到本机。
- 本阶段外部插件只可声明 `storage.own` 和 `ui.reminders`；不开放音乐、通知、Codex、网络、系统文件或 shell。
- 包内 JS 不在 Node 主进程中 import/eval，而是在隐藏的、Node 集成关闭的 Electron 沙盒窗口中的 Worker 执行。只加载宿主控制的运行页面，通过有来源验证的窄接口通信。
- CSP 与会话请求过滤阻止网络及 file URL；拒绝新窗口、导航、下载及浏览器权限。禁用额外 Worker、浏览器数据库、缓存、OPFS 存储入口与离屏画布，数据通过宿主独立存储接口保存。
- 存储按插件 ID 分区，512 KB 配额；输入、消息、频率和超时有检查。心跳或命令超时结束对应执行环境，不依赖插件自愿退出。
- 运行身份、来源、启用状态和权限不能由插件快照覆盖。外部提醒在隐私模式固定只显示插件名称及提醒数量，不能通过自称“隐私摘要”显示任务正文。
- 发布者签名暂未实现。隔离和预算检查不能保证消除所有浏览器漏洞或瞬时资源消耗，仍只应导入可信来源，后续需要继续安全审查。

执行方案遵循 [Electron 安全建议](https://www.electronjs.org/docs/latest/tutorial/security) 中关闭 Node 集成、启用上下文隔离和进程沙盒、使用 CSP、限制导航与校验 IPC 来源的原则；本项目的实际限制另由代码与以下测试验证，不以“独立进程”代替安全边界。

## 验证

单元回归包括 ZIP 路径与 CRC、权限和版本、不可伪造身份、包校验与隔离、动态安装/卸载、数据恢复、配额、待办全部操作及到期去重，并保留音乐、通知、Codex、开机启动和角色参数回归。

真实沙盒检查包括：ZIP 激活、跨进程命令与存储、禁用重启恢复、Node/DOM/网络/file URL/原生模块/路径访问被拒绝、提醒与卸载重装、重启宿主自动加载，以及无限循环命令不会停掉其他插件。

真实管理器与角色菜单检查包括：未安装不可见、拒绝权限不执行、ZIP 导入及来源标识、表单与刷新草稿、实际提交和清空、编辑/完成/恢复/删除/撤销、禁用启用、卸载重装恢复、字幕提醒。截图和结果位于 `.local/zip-plugin-smoke/`，均使用演示数据及隔离配置。

本轮结果：构建通过，58 项单元检查、8 项真实沙盒检查、9 项 ZIP 界面检查和 15 项原菜单界面回归全部通过。沙盒检查也使用打包后的 ASAR 运行资源执行，验证重启宿主自动加载。ASAR 清单确认包含宿主沙盒资源，但不包含待办示例源码或预装 ZIP。

本地试用程序位于 `release/plugin-preview/v3.2.1/Spine-Pet-Workshop-Portable-v3.2.1-x64.exe`，待办包位于 `release/plugins/Todo-Plugin-v1.0.0.zip`。因原同名便携程序正在使用，测试包另存目录，未关闭旧程序；试用前请退出旧程序。

## 当前接口边界

外部包使用 API v1 与包格式 v1，入口必须预先打包为一个不超过 512 KB 的 JS 模块；本阶段不支持 npm/Node 运行时导入、多文件相对模块导入、自定义 HTML/CSS、插件市场或自动更新。[插件开发规范与接入手册](../PLUGIN_DEVELOPMENT.md) 已按当前实现补齐，后续接口变更需同步修订。

待办可保存最多 80 项任务和最近 20 项删除撤销记录。截止时间使用本机时区输入、UTC 保存；检查间隔 5–120 秒，默认 15 秒。程序未运行或插件禁用时不弹出，重新启用后检查未提醒的逾期任务；专注、锁屏和字幕关闭时不重放被抑制的提醒。
