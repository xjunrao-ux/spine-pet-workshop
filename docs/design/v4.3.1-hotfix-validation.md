# v4.3.1 输入框与设置交互修复

本地修复，不推送远端。

## 复现与处理

- 在真实鼠标按下和松开之间持续刷新插件状态，修复前设置控件会被重建，点击天气插件后仍停留在 DeepSeek；同一次无变化刷新后按钮对象也改变。修复后控件保持，真实点击成功切换到天气。
- 设置渲染按原始模板缓存，避免 DOM 序列化差异导致重复重建；鼠标/键盘操作、输入和原生下拉选择期间延后更新，操作完成或失焦后应用最新状态。
- 独立输入条使用固定的请求尺寸 340 × 76 DIP，移动与跟随均显式携带固定尺寸，移除网页测量到主进程改尺寸的循环。Windows 不可见边框可能令读取到的边界多出少量像素，验证允许 4 DIP 的平台差异。
- 点击输入条设置立即隐藏输入条；角色管理器或本地连接设置获得焦点期间，输入条及快捷功能浮层收起。
