# SpinePet v5.3.1

Windows x64 正式版 · 2026-10-31

修复任务栏图标回退为 Electron 或空白的问题，继续保留 v5.3.0 的模型与语音检索、下载和导入功能。

## 本版变化

- 安装版、便携入口、不同源码目录和测试环境分别使用合适的任务栏标识，避免窗口错误匹配到其他 Electron 快捷方式。
- 任务栏图标按内容持久保存在用户资料目录，避免便携程序临时解包目录失效或旧图标缓存。
- 本地源码启动时注册带完整路径、参数和图标的开始菜单入口；桌面快捷方式修复工具同步这一关联，并备份已有入口。
- 开发通知的自动快捷方式与窗口标识隔离；测试环境先检查隔离条件，避免触发不必要的通知注册。
- 安装版保留既有安装身份、用户资料路径和快捷方式迁移规则；已有角色、语音、插件及设置继续使用。

## 下载与升级

- 安装版：`SpinePet-Setup-v5.3.1-x64.exe`。已有 v5.2.1 及以上安装版可在“更新与开发”检查更新。
- 便携版：`SpinePet-Portable-v5.3.1-x64.exe`。退出旧实例后在固定位置运行新版。
- 附件包含五个既有稳定版插件 ZIP、可选 DSH 桥 TGZ、离线使用说明、自动更新清单及 SHA-256 校验表。
- 升级前退出旧实例。数据仍保存在原 Windows 用户资料目录；未更改角色素材索引或插件版本。
