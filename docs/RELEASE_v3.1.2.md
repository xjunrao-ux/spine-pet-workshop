# Spine 桌宠工坊 v3.1.2

Windows x64 扩展功能版，不接入 AI 对话。

## 更新

- 悬停圆角胶囊、固定设置入口、连续滚动后平滑吸附、边缘调整面板大小。
- QQ／网易云音乐控制、Windows 系统通知、Codex 额度和任务状态，只读本机服务。
- 修复自定义开机启动项已登记后仍被误判为失败的问题。
- 通知入口启用时常驻，查看后只消除红点，无新消息显示空状态，关闭功能才隐藏。
- 预览比例与真实角色统一，预览下方撤销／重做及快捷键；气泡高度方向修正，颜色填充方向保持不变。
- 兼容说明进入角色管理器，系统通知使用铃铛，Codex 使用 GPT / OpenAI 图标。

## 使用与限制

下载 Setup 安装版或 Portable 便携版，无需开发环境。升级保留本机角色与参数，请先退出旧版。

开机启动默认关闭，在“功能 → 应用启动”开启。换用新版便携路径后请重新开启，以更新旧版启动路径。

网易云需开启 SMTC，时长与进度显示 --:--。微信和企业微信当前不走 Windows 系统通知，暂不支持聊天提醒。查看通知不修改聊天已读状态。

Codex 取决于本机已登录 CLI 与服务可用性，不调用模型、不开始任务。第三方插件、时间任务、待办与笔记暂未加入。

附件包含安装版、便携版、SHA256SUMS.txt 与 USAGE-v3.1.2.md。角色素材与 Spine Runtime 许可仍适用，详见项目素材说明。
