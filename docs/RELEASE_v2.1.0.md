# Spine 桌宠工坊 v2.1.0

v2.1.0 是当前正式稳定版本，提供 Windows x64 安装版和便携版。

## 下载

- `Amiya-Desktop-Pet-Setup-v2.1.0-x64.exe`：安装版，可选择安装目录并创建快捷方式。
- `Amiya-Desktop-Pet-Portable-v2.1.0-x64.exe`：便携版，下载后直接运行。
- `SHA256SUMS.txt`：下载完整性校验值。

请不要把 GitHub 自动生成的 `Source code.zip` 当作普通用户安装包。

## 主要更新

- 透明桌宠窗口、系统托盘和右键设置菜单。
- 拖动、重力、任务栏与软件窗口吸附。
- 自动行走、边缘转向和随机动作。
- 尺寸调整、日语语音和简体中文字幕。
- 修复 150% DPI 下窗口持续变大和吸附坐标异常。

## 快速操作

- 左键短按：互动。
- 左键按住：拖动。
- 右键人物：打开设置。
- 单击托盘图标：显示或隐藏。
- 右键托盘图标：设置或退出。

更多说明见 `docs/versions/v2.1.md`。
