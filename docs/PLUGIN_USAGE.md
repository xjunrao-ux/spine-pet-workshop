# 插件下载、安装与使用手册

适用 Windows x64 SpinePet v5.1.3；ZIP 导入自 v3.2.2 起支持。普通用户无需安装 Node.js、pnpm 或开发工具。

## 从哪里找插件

打开[社区插件目录](../community/README.md)，查看功能、作者、最低宿主版本、权限和固定 ZIP 下载入口。目录由 GitHub PR 投稿和维护者审核更新。首次安装使用 ZIP 导入；接入更新功能后，可在“角色管理器 → 更新与开发”检查已安装插件的新版本，确认后下载并替换。

- 计数器：零权限入门示例，可点击加一、清零，重启归零。
- 天气：选装，设置城市后查看当前天气、24 小时和 7 天预报；需独立存储和受控天气查询。
- Codex：选装，读取本机额度和任务状态；需本机 Codex 已登录运行，权限为提醒和 Codex 只读。
- DeepSeek：使用自己的 API Key，流式回复在角色气泡显示；人设、记忆和输入框设置在管理器配置。
- DSH：连接已配置且显式授权的本机 DSH 桥会话，详见 [DSH 插件](../examples/dsh-pet-plugin/README.md)。
- 音乐、系统通知和待办为内置插件，不用下载。内置项可以禁用，不能用 ZIP 覆盖或卸载。

## 安装

1. 下载作者在 Release 上传的插件 ZIP 附件。GitHub 的 Source code.zip 是源码，不是插件安装包；不要解压插件 ZIP。
2. 如需核对摘要，在 PowerShell 运行 `Get-FileHash -Algorithm SHA256 -LiteralPath '下载的插件.zip'`，与社区条目的 `sha256` 比较，大小写不影响比较。
3. 打开“角色管理器 → 扩展 → 导入插件 ZIP”，选择文件。
4. 核对名称、ID、版本、权限和来源，确认后才安装执行；取消不会安装。
5. 查看扩展页状态，悬停桌宠并打开新入口。天气需要先在管理器的“城市设置”选城市；Codex 没有可用本机状态时可能暂不显示入口。

哈希核对只确认下载与登记内容一致，不认证作者身份；应同时查看源码、作者和权限说明。

扩展列表通过拖动卡片排序，自动同步桌面菜单；卡片没有上下排序箭头。主程序和插件分开更新：“扩展 → 检查插件更新”可进入更新页。在线更新核对 ZIP 的 SHA-256、身份、权限、最低宿主版本与配置格式；保留启用状态、配置和独立数据。新增权限须在更新确认框中核对，启动失败会恢复旧版；已产生的插件业务数据不会自动回滚。未收录插件仍由作者提供新版 ZIP。

## 更新、禁用和卸载

下载新版，重新导入相同 ID 包会替换并启用插件，保留配置和持久化数据。宿主 EXE 更新不会自动更新已安装 ZIP。宿主不比较版本新旧；降级可能遇到数据不兼容，不要忽略作者说明。

- 禁用：停止插件并移除菜单入口，保留数据。
- 重启：重新创建运行实例；纯内存内容丢失，持久化内容由插件恢复。
- 卸载：停止运行并移除安装记录，保留独立数据和包缓存；同 ID 重装可恢复已保存的数据。卸载不是彻底清理。

更新前退出桌宠，必要时备份 `%APPDATA%\spine-pet-workshop\`。不要通过删除配置文件解决版本错误，以免丢失数据。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 不能导入，提示缺少 plugin.json | 下载正确的插件附件，不能用 Source code.zip；请作者检查根目录结构 |
| 提示不支持的权限或接口 | 核对宿主版本与作者说明，不要自行改清单绕过检查 |
| 插件不显示 | 在扩展页确认启用和运行状态；某些入口只在有数据时出现 |
| 启动失败或超时 | 查看扩展页原因，尝试重启；向作者提交插件/宿主版本及复现步骤 |
| EXE 更新了，插件仍是旧版 | 下载新版 ZIP 再导入，扩展页核对插件自己的版本 |
| 计数重启后丢失 | 计数器示例只演示内存状态，这是预期行为 |
| 任务名称、城市等不希望出现在公开报告 | 删除截图和日志中的私人内容后再提交 Issue |

使用问题在作者源码仓库反馈；收录链接失效、更新或下架问题在本项目提 Issue。想自己开发，阅读[快速入门](PLUGIN_QUICKSTART.md)、[完整规范](PLUGIN_DEVELOPMENT.md)及[投稿流程](../community/CONTRIBUTING.md)。
