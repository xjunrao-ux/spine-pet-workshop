# 角色参数与扩展接口

v2.3.1 开发版开始，参数按角色保存，互不影响。内置角色保存在用户资料目录的 `workshop-settings.json → characterParameters`，导入角色保存在各自的 `character.json → parameters`。切换角色不会清除配置，旧角色自动获得默认值，不需要重新导入。

## 参数合同 v2

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| schemaVersion | 2 | 参数结构版本；兼容迁移 v1 的整体偏移 |
| audioStartOffsetMs | 0 | 起点独立偏移，-30000～30000 毫秒；负数提前、正数延后开始 |
| audioEndOffsetMs | 0 | 终点独立偏移，同范围；负数提前、正数延后结束 |
| modelScalePercent | 60 | 每个角色的窗口/人物大小，30%～120%，右键大小菜单也会保存此参数 |
| fontSizePx | 13 | 60% 角色比例时的基准字号，8～24 像素；实际字号随角色比例适度缩放并限制在 8～30 像素 |
| bubbleOffsetY | 0 | 气泡纵向偏移，-250～250 像素；负数向上、正数向下，限制在窗口内 |
| bubbleTransparency | 24 | 气泡背景透明度，0% 不透明、100% 完全透明；不影响文字清晰度 |
| walkDirection | random | random / left / right / none；none 禁用自动及手动行走，仍可拖动 |

原始音频和分句时间轴不修改。起点、终点分别校准并裁切到有效音频范围；起点不早于终点或完全超出范围时不播放，试听会说明原因。单句音频不需要时间轴校准。当前语音不被保存操作打断，新校准从下一次播放应用。旧 `audioOffsetMs` 会迁移为两端相同的偏移，未知扩展字段保留；局部保存不会重置另一端。每句偏差各不相同的累计漂移仍需更新时间轴。

角色大小、字号和背景透明度保存后即时生效。默认气泡位置尽量留在人物上方，长句会压缩字号和内边距；手动高度偏移优先。过长字幕或用户设置过大的字号仍可能占用人物区域。

## 添加参数

1. 在 `electron/character-parameters.mjs` 的 `PARAMETER_FIELDS` 中增加字段说明、默认值、范围或枚举；编辑器自动生成滑条＋数值框或下拉框。
2. 更新同目录 `.d.mts` 类型合同，并在实际消费该参数的模块中实现行为。
3. 添加默认值、边界、旧配置兼容和保存测试。改变结构语义时增加迁移逻辑，不直接丢弃旧配置。

未知字段保留，可用 `extensions` 命名空间保存未来模块的数据；这不是允许执行任意插件代码的接口。保存请求按角色合并参数，并限制数据大小。

## 窗口接口

设置预加载桥提供 `getCharacterConfig(id)`、`saveParameters(id, parameters)`、`previewModel(payload)` 与 `previewVoice(payload)`。主进程只接受当前设置窗口发起的新接口请求。导入预览只授权用户通过选择器选择的目录／文件，并使用临时 `pet-preview` URL 提供匹配的骨骼、贴图及音频，不开放任意磁盘文件；关闭设置窗口后授权失效。

预览不创建角色、不切换正在使用的桌宠；库中参数只有点击“保存设置”后写入。气泡高度在预览中即时变化，在桌宠窗口中根据实际可见空间限制，避免越界。
