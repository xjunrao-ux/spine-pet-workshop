# 模型与语音检索下载

“导入角色”页先显示素材获取教程，其下是“搜索角色模型与语音”。搜索区使用主题色边框、大号输入框、放大镜与搜索按钮。按中文角色名、英文名、模型编号或服装系列查找素材，也可按回车或点击搜索。多个关键词用空格隔开，例如“阿米娅 近卫”。可筛选干员小人、干员动态立绘、敌人战斗模型（含首领）。皮肤和敌人变体分别显示，结果支持翻页。

搜索结果抽屉默认收起，输入文字或切换分类时不会自动展开；点击搜索或按回车才执行检索并展开。搜索后可用“收起搜索结果／展开搜索结果”切换，下载进度仍然显示。修改关键词或分类后再次点击搜索，分页继续使用上次提交的条件。

点击“下载并填入导入”，程序会从 GitHub 下载该文件夹里的完整素材，显示下载进度，并自动填写角色名称、骨骼和图集。下载完成后仍由用户在原导入预览中确认，点击“导入并设为当前桌宠”才创建和切换角色。

搜索结果中的“角色语音”列出该角色可导入的日语、普通话、英语、韩语及个性化语音，以实际收录情况为准。皮肤优先选择专属配音；使用默认配音时标明“共用语音”，不同异格及职业形态不会互相混用。没有匹配语音或字幕的模型会显示未收录提示。

点击“下载语音并填入”，程序校验并保存 OGG 后自动设置长音频、角色 ID 和语种，恢复匹配该快照的内置时间轴与中文字幕，并准备分句试听。模型和语音可按任意顺序下载。两者准备好后，点击原来的导入按钮即可一起导入。仍可使用原来的本地音频选择和自定义配置入口。语音取消或失败会保留原有音频选择；下载页按钮可打开精确语音文件。

语音与字幕区域先显示方案 A“明日方舟长音频”（自动分句与中文字幕），再显示方案 B“单句音频”；窄窗口按相同顺序排列。

点击“打开下载页”可直接打开对应模型的 GitHub 文件夹。文件名中的 `#` 会正确编码，能够定位皮肤目录。下载失败可重试或改用该入口；取消或失败不会清空之前选择的本地模型和角色名称。

索引随应用附带，搜索不联网。下载需要访问 `raw.githubusercontent.com`，固定到索引对应的仓库提交，逐文件核对大小和 Git blob SHA-1。模型缓存位于用户资料目录的 `model-downloads/<提交>/<模型类型>/<目录>`，语音缓存位于 `voice-downloads/<提交>/<语种>/<角色 ID>`；再次选择会校验并复用完整缓存。中断的临时下载不会成为可导入的素材。关闭管理器或退出应用会取消进行中的下载。

部分源骨骼没有扩展名，下载后识别内容并在本地补 `.json` 或 `.skel`，以便原导入器加载。源文件内容不变；预览仍按现有 Spine 3.8 兼容规则验证。

## 数据范围

索引文件：`electron/data/ark-model-catalog.json`，仅包含名称、目录和文件校验信息，不包含原始模型素材。快照提交为 `e65fb9147846b64bcf2df956b8cd8da77a51b9b8`，索引整理日期 2026-10-26，仓库模型数据提取日期 2026-09-29。

| 分类 | 实际模型文件夹 |
| --- | ---: |
| 干员基建小人（含时装） | 953 |
| 敌人战斗模型 | 2,063 |
| 干员动态立绘 | 96 |
| 合计 | 3,112 |

3,091 个名称取自仓库元数据，8 个按同一敌人 ID 从游戏数据补全。其余 13 个显示“名称待核实”，可按编号检索和下载。元数据中另有 109 条没有对应模型目录的记录，不列为可下载模型。敌人模型包含普通敌人、首领等游戏内对象，分类保留仓库的素材含义。

来源：[模型仓库快照](https://github.com/isHarryh/Ark-Models/tree/e65fb9147846b64bcf2df956b8cd8da77a51b9b8)、[仓库名称数据](https://github.com/isHarryh/Ark-Models/blob/e65fb9147846b64bcf2df956b8cd8da77a51b9b8/models_data.json)、[补充敌人名称](https://github.com/Kengxxiao/ArknightsGameData/blob/master/zh_CN/gamedata/excel/enemy_handbook_table.json)。

语音索引为 `electron/data/ark-voice-catalog.json`，包含 1,407 个音频文件的路径、大小和 Git blob SHA，不包含音频内容。来源是 [Ark-Voice 快照 79584841f7a2](https://github.com/isHarryh/Ark-Voice/tree/79584841f7a28f9d029ec2dc1b72444bce87eb1e)，与现有内置 `voice_data.json` 完全匹配。可导入的语种必须同时具备音频、匹配时间轴和中文字幕。

更新索引时，应从同一提交的递归 Git tree 与 `models_data.json` 生成条目，保留实际文件名（包括大小写、空格、`$` 和 `#`），用 tree 中的文件大小与 blob SHA 生成下载清单。只纳入实际存在的模型目录，无法核对的名称保持未知。变更后运行 `pnpm test:models`、`pnpm build` 和 `pnpm test:models:ui`。

## 验证

- `pnpm test:models`：名称检索、全目录覆盖、分页、URL 编码、完整下载、缓存修复、JSON 骨骼、取消、超时、校验失败、语音索引匹配、皮肤回退和字幕可用性。
- `pnpm test:models:ui`：在独立测试资料目录启动隐藏窗口，使用匹配索引哈希的本地素材模拟网络响应，验证实际 IPC、失败保留、取消恢复、分句试听、模型与 35 句中文字幕一起导入，以及交换后布局和窄窗口排版。

图形测试需要本地基建阿米娅模型，以及语音快照中的 `voice/char_002_amiya.ogg`。语音测试文件默认放在 `.local/voice-test-assets/char_002_amiya.ogg`，也可通过 `MODEL_VOICE_TEST_OGG` 指定已取得的相同文件；测试不会在线获取素材。

图形测试不操作个人安装目录或已有角色配置。
