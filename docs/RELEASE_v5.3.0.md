# SpinePet v5.3.0

Windows x64 正式版 · 2026-10-31

在“导入角色”中按角色名称查找模型与配音，下载后直接预览、试听并导入桌宠。

## 本版变化

- 内置 3,112 套实际模型文件夹的检索索引，支持中文名、英文名、模型编号和服装系列；可筛选干员小人、动态立绘与敌人战斗模型。
- 一键下载完整骨骼、图集和贴图，自动填入原有导入表单；支持进度、取消、失败重试、文件校验和缓存复用。也可打开对应 GitHub 下载页。
- 集成配音语种选择与语音下载，优先皮肤专属语音，标明共用配音；自动匹配角色 ID、时间轴和中文字幕，准备分句试听后随角色一起导入。
- 素材教程位于检索区上方。搜索框加大并增加明确搜索按钮；结果抽屉默认收起，点击搜索或按回车后展开，可手动收起。
- 语音方案 A 为明日方舟长音频及自动字幕，方案 B 为单句音频。下载的无扩展名骨骼按内容补齐导入格式。
- 提供本地源码启动版桌面快捷方式修复工具，备份并校验失效入口。安装版继续沿用现有安装与任务栏标识，不更换用户数据目录。

## 下载与升级

- 常规安装：`SpinePet-Setup-v5.3.0-x64.exe`。
- 便携使用：`SpinePet-Portable-v5.3.0-x64.exe`，放在固定位置运行。
- 退出旧实例后覆盖安装或运行新版。已有角色、插件和设置继续使用原用户资料目录；v5.2.1 及以后的安装版也可在“更新与开发”检查更新。
- 五个选装插件、可选 DSH 桥、离线说明和 SHA-256 校验表随附件提供。插件版本沿用既有稳定版。

## 素材范围

搜索索引可离线使用，下载需要能访问 GitHub 原始文件。模型及语音来自固定的上游快照，按文件大小和 Git blob SHA 校验；上游更新不会自动改写本次索引。

模型中 13 个敌人变体名称尚未确认，可按编号查找。配音以已收录音频、匹配时间轴和中文字幕为准，未收录的角色或语种会明确提示。未包含自动更新上游素材索引的功能。
