# SpinePet v5.2.3

Windows x64 正式版 · 2026-10-25

针对 v5.2.2 中更新图标文件后，Windows 任务栏仍可能显示 Electron 图标的问题，调整应用标识及快捷方式迁移。

## 本版变化

- Windows 任务栏使用新的固定标识；保留原安装 appId、升级位置及用户数据目录。
- 安装器将现有桌面和开始菜单快捷方式迁移到相同任务栏标识，不新建用户已删除的快捷方式。
- 安装版启动时备份并更新匹配当前 EXE 的旧快捷方式图标和标识，保留启动参数。
- 脚本版使用独立任务栏标识；管理器、连接设置等窗口统一设置 ICO 和重新启动信息。
- 便携版仍将图标和启动命令指向长期保留的外层 EXE。

## 升级

安装版退出旧实例后覆盖安装；v5.2.1/v5.2.2 可通过“更新与开发”更新。便携版需下载并运行新版。已有角色、插件及设置继续沿用原目录。

本版继续提供安装版、便携版、五个选装插件、DSH 桥、离线说明、更新清单和校验文件。
