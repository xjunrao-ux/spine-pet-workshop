# DeepSeek 桌宠聊天 v1.1.1

点击角色触发、左右调宽及圆形发送按钮需要 SpinePet v5.1.3 或更新的宿主。只更新插件 ZIP 不会升级宿主界面。

## 使用

1. 在角色管理器 → 扩展导入 DeepSeek-Plugin-v1.1.1.zip，相同插件 ID 会更新并保留已有资料。
2. 展开“DeepSeek 对话 → 设置、权限与兼容说明”。连接与隐私、人设与记忆均在这里。
3. 点击配置 API Key，由宿主可信窗口填写；模型选项也在管理器中。
4. 在插件设置的“对话触发与输入框”中选择鼠标悬停或点击角色打开输入条；点击模式下，拖动角色不会打开聊天。
5. 拖动输入条左右边缘可调整宽度（240–720 px），也可在设置中调节；宽度会自动保存。左侧手柄用于移动位置，设置中的按钮可恢复跟随角色。
6. 在输入条发送一句话，回复以流式气泡出现；生成中可点击停止。气泡支持选中文字和较长内容滚动，插件设置从上方已有的设置入口打开。

用户主动输入才调用模型，悬停、安装、重启、修改人设不触发付费请求。默认一至三句话简短聊天；不会修改文件、运行工具或创建日程。

## 资料与隐私

角色人设和手工记忆在角色管理器编辑，后续聊天会发送给 DeepSeek。它们不是自动提取的记忆。Key 由宿主加密保存，插件读不到明文。最近 20 条历史和资料保存在本机；可在管理器清理聊天，清理不会删除服务商已经收到的内容。

API 连接只使用 DeepSeek 官方服务，费用计入你的账户；此插件与 DSH 项目任务插件独立。
