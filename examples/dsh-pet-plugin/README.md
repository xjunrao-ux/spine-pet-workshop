# DSH 会话伙伴 v1.1.0

桌宠工坊的独立 ZIP 插件。连接用户已运行、已授权的 DSH 会话，使用 DSH 原有模型、工作目录、工具和审批。

## 安装与连接

1. 使用 **2026-10-22 本轮 UI 更新后的桌宠工坊**（宿主开发版本仍为 4.2.2）。旧的 4.2.2 构建缺少管理器设置页和独立 AI 尺寸。
2. 在 DSH 中安装并启动配套 dsh-pet-bridge；先打开要交给桌宠操作的项目会话。
3. 使用 DSH 桥接插件提供的管理方式，为桌宠签发连接令牌，授权指定会话及所需能力。取得服务根地址，例如 http://127.0.0.1:39217/pet-bridge/v1/。实际端口由服务给出；不要使用 DSH GUI 的端口。
4. 桌宠角色管理器 → 扩展 → 导入插件 ZIP，选择 DSH-Pet-Plugin-v1.1.0.zip，检查并授权所列权限。
5. 进入角色管理器 → 扩展 → DSH 会话伙伴 → 设置、权限与兼容说明，点击“配置连接”。在**宿主可信窗口**填写根地址和连接令牌。令牌不是模型 API Key；插件读不到明文令牌。
6. 在管理器配置区点击“连接”，在桌宠授权会话页点击“选择 → 确认切换”。显示“实时连接就绪”后，在对话页发送任务。

根地址务必包含 /pet-bridge/v1/；插件使用固定的 /info 等相对路径。只支持显式端口的 http://127.0.0.1 或 http://[::1]，不扫描端口、不读取 ~/.dsh，不自动创建或恢复 Agent。历史不可用项标灰，先去 DSH 打开会话。

保存配置只代表登记授权，不代表服务已经连接。修改配置后请重新连接和选会话；旧授权的未决发送记录会隔离显示，不会自动提交给新服务。

## 功能

- 对话：近期 20 条已提交历史、流式可见文本、截断说明。
- 任务：执行状态与最近工具摘要整合为输入框上方的单行滚动条；活动详情仍由协议校验，取消始终绑定准确 activityId。
- 停止：确认具体 activityId 后发送取消；等待服务终态，不把断开网络当成取消任务。
- 追加指令：设置中开启“允许追加指令”，且服务握手声明 message.steer 后才可使用。普通任务不会在忙碌时偷偷转为追加。
- 恢复：先快照后 SSE；断线只重连读取并查询台账，绝不自动重发变更命令。超时不等于任务没有执行。
- 本机资料：可在角色管理器编辑一份人设和手工记忆。**当前 DSH 桥没有 persona.update，保存不会影响 DSH 回答，也不会把资料伪装成用户消息。**
- 可选提醒：设置默认关闭；开启后，仅对新收到的活动结束/待审批去重提醒。

当前桥接服务没有桌宠审批回答、反向桌宠工具或日程创建能力；审批请在 DSH 中处理。没有角色动画、文件操作、剪贴板、自动记忆提取或跨插件执行接口。

## 数据与权限

插件清单声明 net.local、storage.own、ui.reminders。当前导入器对清单整体授权；提醒功能默认关闭，不是可单独勾选的权限项。连接令牌由宿主按插件身份加密保存。

本机资料、少量显示缓存和发送记录以本机明文数据保存。历史缓存可在插件设置关闭；未决发送凭证查清前仍保留。缓存最多两个会话、合计 160KiB，整个持久状态预算 384KiB。最多保留八条未决变更记录，已结束记录精简保留最近 32 条。

“清理本机显示缓存”不删除 DSH 会话、历史、连接令牌、本机资料或未决记录。保存空的人设/记忆即可清除相应资料。关闭面板或切会话后不保证恢复未发送草稿；同一会话实时刷新保持输入与光标。切换会话前有确认提示。

断开、禁用和卸载会关闭桌宠的网络连接，DSH 中已经接受的任务可能继续运行。取消也不能撤销已经完成的代码或文件修改。

## 故障处理

| 提示 | 处理 |
| --- | --- |
| 需要重新授权 / 401 / 403 | 检查令牌、客户端与会话授权，再配置连接；不自动重试 |
| 会话不可用 | 先在 DSH 中打开相应项目会话，再刷新列表 |
| 结果未知 | 点击“查询发送结果”，或去 DSH 核对；不要根据超时重跑任务 |
| 服务繁忙 / OVERLOADED | 稍后重新查询；查询失败不会把正在运行的任务判成失败 |
| 目标过期 / EXPIRED | 当前活动已变化，重新同步后再确认目标；不会自动取消下一条活动 |
| 多次连接失败 | 最多五轮自动退避后停下，检查服务和根地址，再手动连接 |
| 本机记录保存失败 | 新提交已禁止，保留原始数据，检查本机存储后重启 |
| 仅展示同步后的增量 | 同步发生在生成过程中；完整消息到达后会自动替换，不是消息丢失的完成证明 |

## 开发与验证

从仓库根目录运行：

    pnpm test:dsh-pet
    pnpm build
    pnpm package:dsh-pet
    pnpm test:dsh-pet:sandbox

独立入口是 provider.js，没有运行时外部模块、Node 或任意 fetch。package:dsh-pet 生成 release/plugins/DSH-Pet-Plugin-v1.1.0.zip。

测试分为受控回调的异常顺序测试、现有 DSH 服务代码的真实 HTTP/SSE + 模拟 Harness 集成、真实 Electron Worker 沙盒 + UI 导入验证。它们不调用用户实际运行的 DSH，不修改用户项目，也不产生模型费用。真实 DSH / 真实模型的最终使用仍需按上述步骤连接后验证。

设计及实现差异见仓库 docs/PET_DSH_PLUGIN_IMPLEMENTATION.md；测试结果见 docs/DSH_PET_PLUGIN_TEST_REPORT.md。
