# 天气与预报 v1.2.0

需要本轮 2026-10-22 UI 更新后的桌宠宿主。保留原插件身份 local.spine-weather 和已有地点缓存。

## 城市设置

导入 Weather-Plugin-v1.2.0.zip 后，在角色管理器 → 扩展 → 天气与预报 → 设置、权限与兼容说明中搜索城市并选择；也可输入 WGS84 经纬度。温度单位和自动刷新选项也在这里。

## 查看天气

桌宠菜单的天气图标只显示当前天气、未来 24 小时、7 天预报三个页面，保持紧凑尺寸；不再包含城市设置页。无数据时请先去角色管理器选城市，再点击刷新。

只通过宿主的 weather.read 查询 Open-Meteo。城市或坐标会发送给天气服务，不需要定位权限。离线保留缓存并标记失败/过期。Open-Meteo 当前天气是模型估算，城市资料来自 GeoNames；免费接口适用于非商业用途。
