# Display fonts

- Barlow Condensed Medium/Bold: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/barlowcondensed), SIL OFL, local license: BarlowCondensed-OFL.txt.
- Noto Sans SC Bold: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/notosanssc), SIL OFL, local license: NotoSansSC-OFL.txt. Display subset supplied by Google Fonts CSS API; covers the Chinese characters in the site text.

These are alternative display fonts used to achieve condensed Latin and square Chinese title shapes. They are not the proprietary font files from the reference site.
