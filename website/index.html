SpinePet 是一款 Windows 明日方舟桌宠。把干员基建小人的日常动画和游戏原声语音带到桌面，工作、学习时也能看到熟悉的干员，听到角色台词。
支持检索并导入兼容的动态立绘、敌方战斗模型。

02 / USER GUIDE

新手教程

从下载安装明日方舟桌宠，到导入干员与原声语音，按步骤操作即可。

普通使用下载 EXE 即可，
无需安装开发工具。

完整使用手册 ↗

下载安装，启动第一个桌宠。

  1. 下载 Windows 安装版并完成安装；也可以直接运行免安装版。
  2. 启动后会显示内置阿米娅。左键拖动调整位置，短按互动，右键打开菜单。
  3. 右键桌宠 → 角色管理器，在角色库切换角色；点击「设置」调整大小和语音。

关闭管理器不会退出桌宠。要隐藏或退出，请使用桌宠或系统托盘的右键菜单。

06 / HELP DESK

常见问题

下载、角色、语音与更新，
先在这里找答案。

仍需帮助？提交反馈 ↗
下载后，应该打开哪个文件？＋

普通使用请选择 SpinePet-Setup 或 SpinePet-Portable 的 EXE 文件。Setup 是安装版，Portable 可直接运行。GitHub 的 Source code.zip 是源码，不能当安装包使用。目前提供 Windows x64 版本。

游戏原声语音和其他干员怎么添加？＋

打开「导入角色 → 搜索角色模型与语音」，输入角色名或编号，下载后预览、试听，确认再导入。可选择语种，语音与中文字幕需与角色 ID 对应。也可导入本地完整的 Spine 3.8 模型文件夹。查看图文教程 ↗

对话插件装好就能聊天吗？＋

DeepSeek 插件需要在扩展设置中填写自己的 API Key，费用由服务商账户承担。DSH 会话伙伴需要另行配置已授权的本机桥服务。安装前可查看各插件的配置条件和权限。

怎么更新？角色和设置会保留吗？＋

安装版可在「更新与开发」中检查并下载新版本，便携版请到发布页下载。正常升级保留角色和设置，升级前先退出旧版。插件需要单独确认更新，也可重新导入同 ID 的新 ZIP。

怎么隐藏或退出桌宠？＋

关闭角色管理器后桌宠仍会运行。右键桌宠或系统托盘图标，可以隐藏、显示或退出整个应用。

数据在哪里？支持哪些通知？＋

角色、设置和插件资料保存在本机 %APPDATA%\spine-pet-workshop\，退出后可备份。通知功能读取 Windows 通知中心消息，不直接读取微信或企业微信聊天。对话插件会向配置的服务发送相关对话。
