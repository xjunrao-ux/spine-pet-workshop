下载、打开，和它打个招呼。

  1. 下载 Windows 安装版或免安装版，启动 SpinePet。
  2. 首次启动自带阿米娅。左键拖动位置，短按互动，右键选择动作。
  3. 右键桌宠打开「角色管理器」，在角色库选择你想使用的角色。

关闭管理器后，桌宠会继续陪伴。要退出，请右键桌宠或系统托盘图标。

A FEW MORE THINGS

你可能还想知道。

反馈问题 ↗
下载后，应该打开哪个文件？＋

普通使用请选择 SpinePet-Setup 或 SpinePet-Portable 的 EXE 文件。Setup 是安装版，Portable 可直接运行。GitHub 的 Source code.zip 是源码，不能当安装包使用。目前提供 Windows x64 版本。

怎么导入新的角色？＋

打开「导入角色 → 搜索角色模型与语音」，输入角色名或编号，下载后预览、试听，确认再导入。也可选择本地模型文件夹，需要兼容 Spine 3.8，包含骨骼、图集和完整贴图。查看图文教程 ↗

对话插件装好就能聊天吗？＋

DeepSeek 插件需要在扩展设置中填写你自己的 API Key，相关费用由服务商账户承担。DSH 会话伙伴需要另行配置已授权的本机桥服务。每个插件的配置与权限可在安装前查看。

怎么更新？原来的角色和设置会丢吗？＋

安装版可在「更新与开发」中检查并下载新版本，便携版请到发布页下载。正常升级会保留角色和设置；升级前先退出旧版。插件需要单独确认更新，也可以重新导入同 ID 的新 ZIP。

怎么隐藏或退出桌宠？＋

关闭角色管理器后桌宠仍会运行。右键桌宠或系统托盘图标，可以隐藏、显示或退出整个应用。

数据保存在哪里？支持哪些通知？＋

角色、设置和插件资料保存在本机 %APPDATA%\spine-pet-workshop\，退出后可以备份。通知功能读取 Windows 通知中心的消息，不支持直接读取微信或企业微信聊天。对话插件会向你配置的服务发送相关对话。
