# 内置明日方舟语音配置来源

本目录是 v2.2.4 的默认离线数据快照，下载日期为 2026-09-23。用户可以在导入界面的高级选项中用新版 JSON 覆盖这些默认值。

- `voice_data.json`：Ark-Voice，<https://github.com/isHarryh/Ark-Voice>
- `charword_table.json`：ArknightsGameData 简中数据，<https://github.com/Kengxxiao/ArknightsGameData/tree/master/zh_CN/gamedata/excel>

应用只使用时间点、语音编号和中文字幕进行本地匹配，不包含 Ark-Voice 的角色音频。用户仍需自行选择合法取得的角色长音频。
